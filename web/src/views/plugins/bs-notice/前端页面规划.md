# 消息通知系统前端页面规划文档

## 1. 目录结构

```
web/src/views/plugins/bs-notice/
├── api/                          # API 接口定义
│   └── index.ts                  # 消息通知相关 API
├── components/                   # 组件目录
│   ├── UnreadNoticeBadge/        # 未读消息徽章组件（用于顶部导航栏）
│   │   └── index.vue
│   ├── NoticeList/               # 消息列表组件（可复用）
│   │   └── index.vue
│   └── NoticeDetail/             # 消息详情组件
│       └── index.vue
├── list/                         # 消息列表页面
│   ├── index.vue                 # 主页面
│   ├── crud.tsx                  # CRUD 配置（使用 fast-crud）
│   └── types.ts                  # TypeScript 类型定义
├── detail/                       # 消息详情页面（可选）
│   └── index.vue
└── 前端页面规划.md               # 本文档
```

## 2. 功能模块

### 2.1 消息列表页面 (`list/index.vue`)

**功能说明：**
- 展示当前用户的所有消息
- 支持筛选：全部/未读/已读/待办
- 支持按消息类型筛选：系统通知/业务消息/告警消息/待办提醒
- 支持按优先级筛选：紧急/普通/低
- 支持搜索（标题、内容）
- 支持批量操作：批量标记已读、批量删除
- 支持单个操作：查看详情、标记已读、标记已处理/忽略、删除

**页面布局：**
```
┌─────────────────────────────────────────────────────────┐
│  消息中心                                    [刷新] [设置] │
├─────────────────────────────────────────────────────────┤
│  [全部] [未读] [已读] [待办]  [系统通知▼] [紧急▼] [搜索] │
├─────────────────────────────────────────────────────────┤
│  ☐ 标题             类型    优先级  发送人   时间    操作 │
│  ☐ 预订单审批通过   业务消息  普通   张三   2小时前  [详情]│
│  ☐ 【告警】资源冲突  告警消息  紧急   系统   5小时前  [详情]│
│  ☐ 上刊工单待审批   待办提醒  普通   李四   1天前    [详情]│
│  ...                                                      │
├─────────────────────────────────────────────────────────┤
│  [批量标记已读] [批量删除]         [1] [2] [3] ... [下一页]│
└─────────────────────────────────────────────────────────┘
```

**技术实现：**
- 使用 `fast-crud` 框架
- 使用 `useFs` hook
- 自定义列渲染（优先级标签、消息类型图标）
- 自定义操作按钮

### 2.2 未读消息徽章组件 (`components/UnreadNoticeBadge/index.vue`)

**功能说明：**
- 显示未读消息数量（红色徽章）
- 点击后弹出消息列表（下拉菜单）
- 支持快速操作：标记已读、跳转详情
- 实时更新未读数量（轮询或 WebSocket）

**使用场景：**
- 顶部导航栏右侧用户菜单旁
- 可集成到现有的 `layout/navBars/breadcrumb/user.vue` 中

**组件设计：**
```
┌─────────────────────────┐
│  🔔 3                   │  ← 点击后弹出
└─────────────────────────┘
         ↓
┌─────────────────────────┐
│  未读消息 (3)            │
├─────────────────────────┤
│  ☐ 预订单审批通过        │
│     2小时前    [查看]    │
├─────────────────────────┤
│  ☐ 【告警】资源冲突      │
│     5小时前    [查看]    │
├─────────────────────────┤
│  ☐ 上刊工单待审批        │
│     1天前      [查看]    │
├─────────────────────────┤
│  [查看全部消息]          │
└─────────────────────────┘
```

**技术实现：**
- 使用 `el-badge` 显示数量
- 使用 `el-popover` 或 `el-dropdown` 显示下拉列表
- 调用 API 获取未读消息列表
- 支持定时刷新（每30秒）或 WebSocket 推送

### 2.3 消息详情组件 (`components/NoticeDetail/index.vue`)

**功能说明：**
- 显示消息完整内容
- 显示关联业务信息（如果有）
- 支持操作：标记已读、标记已处理/忽略、跳转业务页面
- 支持富文本/Markdown 渲染

**技术实现：**
- 使用 `el-dialog` 或独立页面
- 支持 `jump_url` 跳转
- 支持业务关联跳转（`rec_table` + `rec_id`）

### 2.4 消息列表组件 (`components/NoticeList/index.vue`)

**功能说明：**
- 可复用的消息列表组件
- 支持自定义筛选条件
- 支持自定义操作按钮
- 可用于不同场景（全部消息、未读消息、待办消息）

## 3. API 接口设计

### 3.1 API 文件 (`api/index.ts`)

```typescript
// 获取未读消息数量
export function getUnreadCount(): Promise<{ count: number }>

// 获取用户消息列表
export function getMyNotices(params: {
  msg_type?: number,
  read_status?: number,
  handle_status?: number,
  limit?: number,
  offset?: number
}): Promise<{ data: NoticeItem[], total: number }>

// 标记消息为已读
export function markAsRead(id: string): Promise<void>

// 标记消息为已处理
export function markAsHandled(id: string): Promise<void>

// 标记消息为已忽略
export function markAsIgnored(id: string): Promise<void>

// 删除消息（软删除）
export function deleteNotice(id: string): Promise<void>

// 批量标记已读
export function batchMarkRead(ids: string[]): Promise<void>

// 批量删除
export function batchDelete(ids: string[]): Promise<void>
```

### 3.2 数据类型定义 (`list/types.ts`)

```typescript
export interface NoticeItem {
  id: string
  notice_id: string
  msg_type: number  // 1系统通知 2业务消息 3告警消息 4待办提醒
  title: string
  content?: string
  jump_url?: string
  priority: number  // 1紧急 2普通 3低
  read_status: number  // 0未读 1已读
  read_time?: string
  handle_status: number  // 0未处理 1已处理 2已忽略
  handle_time?: string
  send_time: string
  sender_name?: string
  rec_table?: string
  rec_id?: string
}

export interface PageQuery {
  page?: number
  limit?: number
  msg_type?: number
  read_status?: number
  handle_status?: number
  search?: string
}
```

## 6. 样式设计

### 6.1 消息类型图标/颜色
- 系统通知：蓝色，图标：📢
- 业务消息：绿色，图标：📋
- 告警消息：红色，图标：⚠️
- 待办提醒：橙色，图标：📌

### 6.2 优先级标签
- 紧急：红色标签
- 普通：蓝色标签
- 低：灰色标签

### 6.3 未读标识
- 未读消息：加粗显示，左侧显示蓝色圆点
- 已读消息：正常显示

## 7. 交互流程

### 7.1 查看消息列表
1. 用户进入消息中心页面
2. 默认显示"全部"消息
3. 可以切换标签（全部/未读/已读/待办）
4. 可以筛选消息类型和优先级
5. 可以搜索消息

### 7.2 查看消息详情
1. 点击消息标题或"详情"按钮
2. 打开消息详情对话框或跳转详情页
3. 自动标记为已读（如果未读）
4. 可以执行操作（处理/忽略/跳转业务）

### 7.3 处理待办消息
1. 在"待办"标签下查看待办消息
2. 点击"已处理"或"忽略"按钮
3. 消息从待办列表中移除

### 7.4 未读消息提醒
1. 顶部导航栏显示未读数量徽章
2. 点击徽章弹出未读消息列表
3. 可以快速查看和操作
4. 点击"查看全部"跳转到消息中心

## 9. 技术栈

- **框架**: Vue 3 + TypeScript
- **UI 库**: Element Plus
- **CRUD 框架**: fast-crud
- **状态管理**: Pinia（可选）
- **HTTP 客户端**: axios（通过 `/@/utils/service`）
- **路由**: Vue Router

## 10. 注意事项

1. **权限控制**：所有接口都需要用户登录，使用 `IsAuthenticated` 权限
2. **数据安全**：只显示当前用户的消息，后端已做过滤
3. **性能优化**：
   - 列表使用分页加载
   - 未读数量使用防抖刷新
   - 图片和富文本内容懒加载
4. **兼容性**：确保在不同浏览器和屏幕尺寸下正常显示
5. **错误处理**：API 调用失败时显示友好提示
6. **加载状态**：列表加载时显示 loading 动画
