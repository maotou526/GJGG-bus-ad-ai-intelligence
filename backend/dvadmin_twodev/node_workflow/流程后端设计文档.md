# 工作流后端设计文档

> 最后更新：2026-01-30
> 版本：2.0（基于力软工作流引擎 Python 迁移版）

## 一、概述

### 1.1 系统目标

基于力软 .NET Core 工作流引擎进行 Python/Django 迁移，实现完整的审批流管理系统。

### 1.2 技术栈

| 类别 | 技术 |
|------|------|
| 后端框架 | Django 4.2 + Django REST Framework |
| 数据库 | MySQL 8.0+ / SQLite |
| ORM | Django ORM |
| 缓存 | Redis |
| 异步任务 | Celery |

### 1.3 核心特性实现状态

| 特性 | 状态 | 说明 |
|------|------|------|
| 流程模板设计 | ✅ 已完成 | 可视化设计器，JSON 格式存储 |
| 流程版本管理 | ✅ 已完成 | 支持草稿/正式版本 |

## 四、核心模块详解

### 4.1 流程引擎（WorkflowEngine）

**文件**: `utils/workflow_engine.py`

**核心职责**:
- 解析流程模板 JSON 配置
- 计算下一节点
- 处理不同类型节点
- 计算审核人
- 触发连线 IOC

**主要方法**:

```python
class WorkflowEngine:
    def __init__(self, config: WorkflowConfig):
        """初始化引擎，加载模板配置"""

    # ========== 节点流转 ==========
    def get_next_nodes(self, node_id, operation_code) -> List[Dict]:
        """获取直接下一节点列表（含结束节点）"""

    def get_next_task_nodes(self, begin_node, operation_code) -> List[Dict]:
        """获取下一任务节点（递归处理条件节点等）"""

    # ========== 审核人计算 ==========
    def get_auditors(self, node) -> List[Dict]:
        """根据节点配置计算审核人列表"""

    def _get_auditors_by_role(self, config) -> List[Dict]:
        """按角色获取审核人"""

    def _get_auditors_by_user(self, config) -> List[Dict]:
        """按用户获取审核人"""

    def _get_auditors_by_hook(self, config) -> List[Dict]:
        """通过 IOC 注入获取审核人"""

    # ========== 条件计算 ==========
    def calc_condition(self, condition_node) -> bool:
        """计算条件节点表达式"""

    def calc_confluence(self, node, from_node_id, is_agree) -> int:
        """计算会签结果：1=通过, -1=不通过, 0=等待"""

    # ========== 连线 IOC 触发 ==========
    def get_lines_from_node(self, from_node_id, to_node_id=None) -> List[Dict]:
        """获取从某节点出发的连线"""

    def trigger_line_method(self, line, task_id, node_name, code) -> bool:
        """触发连线绑定的 IOC 方法"""

    def trigger_line_method_before(self, line, task_id, node_name, code) -> bool:
        """触发连线流转前方法（iocNameB）"""

    def trigger_line_method_revoke(self, line, task_id, node_name) -> bool:
        """触发连线撤回方法（iocNameR）"""
```

### 4.2 流程服务（WorkflowProcessService）

**文件**: `process/services.py`

**核心方法**:

```python
class WorkflowProcessService:
    @staticmethod
    def create_flow(scheme_code, title, user, form_data=None, auditors=None) -> Dict:
        """
        创建流程实例
        1. 查询流程模板
        2. 创建流程实例记录
        3. 触发开始节点到第一个任务节点的连线 IOC
        4. 创建第一个任务
        """

    @staticmethod
    def audit_flow(process_id, task_id, operation_code, user, description='', auditors=None) -> Dict:
        """
        审批流程
        1. 验证流程和任务状态
        2. 记录审批日志
        3. 更新任务状态
        4. 判断是否可以流转
        5. 调用 _flow_next 流转到下一节点
        """

    @staticmethod
    def _flow_next(process, task, operation_code, user, engine) -> Dict:
        """
        流程流转到下一节点
        1. 获取直接下一节点（含结束节点）
        2. 触发连线 IOC 方法
        3. 获取任务节点
        4. 判断流程是否结束
        5. 创建下一节点任务
        """

    @staticmethod
    def revoke_audit(process_id, task_id, user) -> Dict:
        """撤回审批"""

    @staticmethod
    def refer_flow(process_id, task_id, user_id, user, des='') -> Dict:
        """传阅流程"""

    @staticmethod
    def sign_flow(process_id, task_id, sign_user_id, user) -> Dict:
        """加签"""

    @staticmethod
    def create_child_flow(scheme_code, parent_process_id, parent_task_id, user) -> Dict:
        """创建子流程"""
```

### 4.3 IOC 注入系统

**目录**: `ioc/`

#### 基类定义（base.py）

```python
@dataclass
class WfMethodParameter:
    """IOC 方法参数"""
    process_id: str = None      # 流程实例 ID
    task_id: str = None         # 当前任务 ID
    node_id: str = None         # 当前节点 ID
    node_name: str = None       # 当前节点名称
    user_id: str = None         # 当前用户 ID
    company_id: str = None      # 公司 ID
    dept_id: str = None         # 部门 ID
    form_data: Dict = None      # 表单数据
    scheme_code: str = None     # 流程编码
    code: str = None            # 操作码

class IWorkflowMethod(ABC):
    """IOC 方法接口"""

    @property
    @abstractmethod
    def name(self) -> str:
        """方法名称"""

    def get_user_ids(self, params: WfMethodParameter) -> List[str]:
        """获取用户 ID 列表（审核人 IOC 需覆盖）"""
        return []

    def execute(self, params: WfMethodParameter) -> bool:
        """执行方法（连线执行 IOC 需覆盖）"""
        return True
```

#### 注册表（registry.py）

```python
class WorkflowMethodRegistry:
    """IOC 方法注册表（单例）"""

    def _auto_discover(self):
        """自动扫描 dvadmin_twodev/**/ioc.py 文件"""

    def register(self, method: IWorkflowMethod):
        """注册 IOC 方法"""

    def get(self, name: str) -> IWorkflowMethod:
        """获取 IOC 方法"""

    def get_user_ids_by_ioc(self, method_name, params) -> List[str]:
        """调用 IOC 方法获取用户 ID"""

    def execute_method(self, method_name, params) -> bool:
        """执行 IOC 方法"""

# 装饰器
def register_workflow_method(cls):
    """自动注册 IOC 方法"""
```

#### 使用示例

```python
# 在任意模块的 ioc.py 文件中定义

)

@register_workflow_method

    @property

    def get_user_ids(self, params: WfMethodParameter) -> List[str]:
        # 根据表单数据获取线路负责人
        line_id = params.form_data.get('line_id')
        # ... 业务逻辑
        return ["user_id_1"]

@register_workflow_method
class LineBindingExecutor(IWorkflowMethod):
    """连线绑定执行方法（连线 IOC）"""

        """连线流转时执行的业务逻辑"""

```

## 六、流程模板 JSON 结构

### 6.1 整体结构

```json
{
  "nodes": [...],    // 节点数组
  "lines": [...],    // 连线数组
  "closeDo": {...}   // 流程关闭操作
}
```

### 6.2 节点类型

| 类型 | 说明 |
|------|------|
| startround | 开始节点 |
| endround | 结束节点 |
| stepnode | 普通审批节点 |
| confluencenode | 会签节点 |
| conditionnode | 条件节点 |
| auditornode | 传阅节点 |
| childwfnode | 子流程节点 |

### 6.3 节点审核人配置

```json
{
  "auditors": [
    {
      "id": "uuid",
      "type": "3",           // 1=岗位, 2=角色, 3=用户, 8=IOC
      "auditorId": "user_id|filter_type",
      "auditorName": "显示名称",
      "condition": ""        // 条件过滤
    }
  ]
}
```

### 6.4 连线 IOC 配置

```json
{
  "id": "line_uuid",
  "from": "node_id_1",
  "to": "node_id_2",
  "operationType": "ioc",    // ioc | sql | interface
  "iocName": "MethodName",   // 流转时触发
  "iocNameB": "MethodName",  // 流转前触发
  "iocNameR": "MethodName",  // 撤回时触发
  "strategy": "1",           // 1=默认, 2=条件
  "agreeList": "agree"       // 允许的操作码
}
```

from django.db import transaction

try:

### 10.5 IOC 扩展

迁移后，在业务模块创建 `ioc.py` 文件即可自动注册 IOC 方法：

```python
# your_app/ioc.py
from apps.node_workflow.ioc.base import IWorkflowMethod
from apps.node_workflow.ioc.registry import register_workflow_method

@register_workflow_method
class MyAuditorMethod(IWorkflowMethod):
    @property
    def name(self) -> str:
        return "MyAuditorMethod"

    def get_user_ids(self, params) -> list:
        # 返回审核人 ID 列表
        return ["user_id_1", "user_id_2"]
```

IOC 自动发现机制会扫描项目中所有 `**/ioc.py` 文件并注册。
