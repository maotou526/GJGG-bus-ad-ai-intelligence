





上海公交广告公司智擎交通广告云脑平台建设方案
（V1.0）






2026年01月



一.项目概述
1项目背景
随着公交广告业务规模持续扩大，自营与代理商运营并行的模式，使得媒体资源统筹调配、广告销售预订、投放执行、效果监测等全链条管理环节的协同难度显著提升，对业务运营的规范化、高效化及智能化管控提出了更高要求。恰逢 AI 技术蓬勃发展的行业浪潮，上海公交广告公司为顺应发展趋势、增强核心市场竞争力，积极探索 AI 技术与广告设计、投放执行、营销运营等全业务流程的深度融合，助力企业实现从传统广告服务商向 “城市级智能营销运营商” 的转型，打造全国领先的 “AI + 公交广告” 生态标杆。在此背景下，公司规划建设一体化广告公司管理系统，通过数字化、智能化手段实现双运营模式下全广告管理流程的统筹管控，全面提升整体运营效率与管理水平
2建设目标
构建统一的媒体库，实现车身、站点广告资源的可视化、精细化管理，资源盘点效率提升 50% 以上。
打通销售、预订、审批、上下刊、监测、分析全业务流程，实现端到端闭环管理，业务处理周期缩短 30%。
搭建多角色协同平台，适配广告公司媒体部及管理层、广告代理商、营运分公司广告专员等核心角色需求，清晰划分自营与代理商运营的流程边界与权责（其中管理层聚焦数据查看、经营决策支撑），跨部门协作效率提升 40%。
引入 AI 智能能力，重点赋能广告审核、线路画像构建、营销方案输出等核心场景，降低人工干预成本，提升广告投放匹配度与营销决策精准度。
建立完善的数据统计分析体系，实现业务数据、财务数据、运营数据的实时监控与多维度分析，为管理层经营决策提供精准数据支撑。
3核心角色
广告公司媒体部：负责全业务流程管控，核心权责包括资源统筹管理、自营广告从预订到上下刊的全流程执行、代理商运营广告的审批管控、数据监控管理等，需具备全权限操作与全局视角。
广告代理商：专注于代理商运营广告的前端业务，核心权责包括客户开发、订单提交、广告画面设计、自主提交上下刊执行，需具备便捷的订单操作、流程追踪与自主执行能力。
营运分公司的广告专员：负责广告执行与车辆调度的协同，核心权责包括按每月一次的频次完成全量广告（自营+代理商运营）的监测工作，反馈投放异常问题（如画面破损、位置偏移），保障运营与广告执行双顺畅及投放效果达标。
广告公司管理层：聚焦企业经营决策，核心权责包括业务数据复盘、运营策略制定、成本效益分析。提供多维度数据统计分析与可视化能力，支持其查看自营 / 代理商业务营收对比、资源利用率、广告投放效果等核心指标，自定义生成经营分析报表，为战略调整和决策制定提供精准数据支撑。
二.核心功能模块设计
1媒体资源库
作为系统核心基础模块，实现公交广告资源的全生命周期管理，涵盖车身广告、站点广告（广告灯箱）两大核心类型，重点强化线路、车辆、媒体类型的专项管理功能，构建结构化媒体资源库，支持资源的数字化建档、状态监控、检索匹配等功能。
资源结构化建档：按“线路-车辆-媒体类型”层级建立资源档案，实现全维度管控：
1.1线路管理
建立线路基础档案（线路名称、运营里程、途经站点、线路走向，配车数、广告车辆数、覆盖人群、刊例价格），支持线路新增、编辑、停用等操作，同步关联线路对应的车辆清单与媒体资源分布。
1.2车辆管理
建立车辆专属档案（自编号、车牌号、车型、所属线路、媒体类型），支持车辆与线路的关联/解绑，实时同步车辆运营状态（报废/营运）；
1.3媒体类型管理
明确划分车身广告（全车身、半车身、车尾贴等）、站点广告灯箱（常规灯箱、大型灯箱、智能灯箱等）细分类型，为每种类型建立标准属性（规格参数、制作要求、刊例价基准），支持类型新增与属性配置。
4. 资源关联建档：
1.4可视化地图管理
基于GIS地图实现资源点位的可视化展示，支持按区域、线路、车辆、媒体类型进行多维度筛选检索，直观呈现资源分布与实时状态。支持兴趣点（POI）匹配，快速筛选符合目标人群的资源点位。
1.5资源状态动态管控
实时同步资源状态变更，预订锁定后自动标记为“预订”状态，避免重复预订；上刊完成后更新为“在刊”状态，同步记录上刊时间、广告内容；到期后自动提醒并恢复“空闲”状态，形成完整的状态流转闭环。同时，关联线路、车辆动态状态，若所属线路调整或车辆检修，自动标记资源为“临时不可用”并提醒相关角色。
1.6线路调线审核
当公交线路、车辆因运营调整发生变动时（同步调度系统），系统自动触发线路调线审核处理流程。审核人员选择受影响的轰轰烈烈 后，系统实时展示该线路关联的全部广告资源清单，涵盖预定、上刊、下刊各状态的资源。
针对每条受影响资源，系统提供两种标准化应急处理方案：
忽略：适用于影响轻微或临时性调整场景，系统不做任何业务变更，仅记录操作日志供后续追溯。
重做：适用于需保障广告投放连续性的场景。系统支持选择同线路或其他线路的可用车辆作为替代资源，自动为原车辆生成下刊工单，同时为新车辆生成上刊工单，实现广告资源的无缝迁移。
2预订管理模块
为广告销售与预订业务提供全流程数字化管控，覆盖从客户与代理商管理、订单创建、审批、续期到变更的完整业务闭环。模块以媒体资源库为基础，实现广告资源的精准匹配与高效预订，保障销售流程规范、高效，并清晰支持自营与代理商运营双模式。
2.1代理商管理
代理商合作伙伴管理功能，实现对代理商的准入、授权与日常运营管理。
代理商基础信息管理：建立代理商专属数字档案，集中维护其公司资质、核心联系人、结算信息、合作等级、合同周期及状态（启用/停用）等基础信息。
销售资源与权限配置：基于媒体资源库，实现对代理商可售资源的精细化授权。支持按媒体类型、线路、车辆/站点等维度，从媒体资源库中灵活筛选并配置各代理商专属的可查看与预订资源池，并关联其独立的代理商刊例价体系，确保双运营模式下业务边界清晰。
2.2客户管理
建立统一的客户信息库，支撑客户关系维护与精准营销。
客户档案管理：系统化记录客户的公司名称、行业分类、统一社会信用代码、联系地址与方式等核心信息。
合作历程视图：整合客户历史订单、合作项目及沟通记录，形成完整的客户合作视图。
客户分类与标签：支持按行业（如快消、金融、地产）等维度对客户进行分类与打标，便于进行分层管理与精准营销
2.3广告预订
实现订单从发起、审批、生成到变更的全生命周期线上化管理，核心流程内置双模式差异化规则。
支持按运营模式（自营/代理商运营）发起订单，录入投放细节（线路信息车辆数量、投放周期、广告内容）。系统自动校验资源档期与对应线路、车辆运营状态，规避排期冲突；支持批量锁点，锁定后发起差异化审批流程，且均需加入营运公司广告专员确认节点：
1.自营广告订单：审批流程需经广告公司媒体部多节点审核（资源可用性、预算合理性、投放策略）→ 营运公司广告专员确认（线路/车辆调度可行性），审批通过后生成正式预订单，后续由广告公司媒体部推进上下刊执行；
2. 代理商运营广告订单：审批流程仅需广告公司媒体部审核资源可用性与合规性→ 营运公司广告专员确认（线路/车辆调度可行性），审批通过后生成预订单，后续广告画面设计、上下刊执行由代理商自主完成。
订单变更流程：已生效预订单如需调整，系统将基于原订单复制生成新版本订单。用户可在新订单上修改投放细节（如更换从媒体资源库中重新选择的资源、调整周期等），修改后发起全新的预订审批流程（流程与原订单一致）。原订单作为历史记录予以保留，以供审计与追溯。新订单审批通过后，将替代原订单成为执行依据，系统同步更新媒体资源库中相关资源的状态与档期，并自动通知所有相关角色。
2.4广告续期
广告续期流程，确保到期业务的平稳延续。系统将在广告到期前7天自动提醒相关责任人，用户可在“续期管理”页面主动发起续期申请。
标准化审批：所有续期申请均视为新的业务订单，必须经过与预订流程完全一致的完整审批流程（区分自营/代理模式），审批通过后方可生效。
两种续期模式：
原车续期：延续原车辆资源的广告投放。系统校验资源档期可用后，发起以“延长原订单结束时间”为内容的审批。
换车续期：为客户更换新的广告资源。需从媒体资源库中选择新车，系统将生成“原车下刊+新车上刊”的整合方案并进入审批。审批通过后，自动联动生成相应的上下刊工单。
统一操作页面：“续期管理”页面集中展示所有续期业务，关键信息一目了然。发起或处理续期时，页面将清晰并列展示原订单信息、原资源详情及续期方案（含新车信息），保障操作依据充分、流程可追溯。
3上下刊执行
实现广告画面合规审查与上下刊现场执行流程深度融合，构建从“画面审核通过”到“施工验收完成”的端到端、标准化、闭环管理体系。通过预设时间节点自动触发、AI智能审核赋能、强化进场安全管控与多角色协同确认，确保广告投放合法合规、执行高效准确、过程全程可溯。
3.1上刊管理
3.1.1自动触发与任务分发
系统基于已审批通过的订单，在计划上刊日期前5个工作日，自动生成上刊工单，并根据运营模式精准推送待办提醒：自营广告推至媒体部施工团队，代理商广告推至对应代理商项目负责人。工单同步抄送媒体部业务专员及营运公司广告专员。
3.1.2上刊申请与材料提报
执行方（媒体部或代理商）通过工单详情页发起“上刊申请”。申请时必须同步上传：若车辆有未下刊的广告则提醒并无法上刊
最终版广告画面文件（符合规格要求的高清图）
相关合规证明文件（如商标授权书、肖像权授权书、专利证书等）
施工方案简述（针对特殊尺寸或安装要求）
3.1.3AI智能预审
提报材料后，系统AI审核助手立即启动自动预审：
画面内容识别：自动识别文字、图案、logo，比对敏感词库与合规规则库，标注潜在违规风险（如绝对化用语、不良导向、侵权元素）。
画面质量检测：校验画面尺寸、分辨率、色彩模式是否符合该媒体位的制作标准。
证明文件核验：初步检查文件完整性。
生成AI预审报告，清晰列明检测项、结果、风险点定位（如用框线标出问题区域）及置信度。
3.1.4人工复核与决策
自营广告：AI预审通过后，流转至媒体部专业审查员，进行创意表达、品牌调性、信息准确性的二次综合审查，并可在AI报告基础上补充批注意见。
代理商广告：AI预审通过后，流转至媒体部合规审查员，重点进行内容合法性与证明文件有效性的复核。
审核结论：审查员给出“通过”、“驳回（需修改）”或“转外部法务审核”意见。若驳回，系统自动将意见及标注图反馈至申请方，要求限期修改重提。
3.1.5营运调度可行性确认
画面审核通过后，工单自动流转至营运公司广告专员节点。专员需结合实时车辆/站点调度计划，确认上刊时间、地点的可行性。若存在冲突，可发起微调协商。
3.1.6进场安全登记与备案
执行方施工负责人通过微信小程序，在计划进场前至少24小时，提交电子进场登记申请，填报施工人员名单、身份证号、预计进场/离场时间、车辆信息、作业工具清单及安全预案。
媒体部安全管理员审核通过后，系统为当次施工生成一个唯一的、限时有效的动态进场备案二维码，并同步至营运公司广告专员备案。
3.1.7现场施工与过程存证
施工人员抵达现场后，向场站管理人员出示小程序中的二维码进行扫码核验，完成电子签到。
施工过程中及完工后，需通过小程序上传至少三张带水印（时间、GPS定位）的现场照片：
施工前：广告位原貌。
施工中：安装作业过程（体现安全措施）。
完工后：广告安装最终效果全景。
小程序支持拍照作为补充证据。
多级验收确认闭环：现场照片上传后，触发以下顺序确认流：
3.1.8媒体部施工管理员确认
线上审核施工质量、画面平整度、有无破损。标记该工单及关联订单状态为“上刊完成”。将关联的媒体资源状态更新为“在刊”。触发“上刊完成”通知至所有相关方。
3.2审查标准能力
动态合规知识库：建立中央化的审查标准库，包含《广告法》条款、各行业特殊规定、市场监管部门最新通告、企业内部控制标准。支持管理员在线更新条款，更新后自动关联在审画面并提醒审查员。
AI审核助手深度赋能：
模型持续学习：基于历史审核案例与审查员反馈，不断优化识别准确率。
多维度检测：除基础违规内容外，增加对“广告标识”（如“广告”字样）是否规范、联系方式是否有效、竞品logo是否误用等场景的识别。
报告生成：自动生成结构化审核报告，支持一键导出，作为合规证据存档。
3.3下刊管理
3.3.1自动触发与任务分发
系统在广告合同约定的投放到期日前5个工作日，自动触发下刊流程，生成下刊工单。推送逻辑与上刊一致（区分自营/代理），并同步提醒媒体部、代理商关注可能的续约事宜。
3.3.2下刊申请
执行方通过工单发起“下刊申请”。申请时需确认下刊原因：
到期正常下刊（系统默认）
客户提前终止（需上传终止协议或客户函）
画面破损/质量问题进行更换（需关联破损报修单）
因线路/车辆调整下刊（需关联调线审核单）
3.3.3下刊审批与调度确认
自营广告：由媒体部业务专员审批下刊申请，确认费用结算等事宜。
代理商广告：由媒体部对接专员进行备案确认。
营运公司调度确认：营运公司广告专员确认下刊时间与调度计划无冲突。
3.3.4进场安全登记与备案
流程与上刊完全一致。施工方需提前提交进场登记，获取动态二维码，确保下刊作业规范、可追溯。
3.3.5现场执行与资源还原存证
施工人员扫码进场后，需完成广告画面的完整、清洁拆除，恢复广告位原状。通过小程序上传关键节点照片：
下刊前：广告在位状态。
下刊中：拆除作业过程。
下刊后：广告位已清洁恢复的原貌。
3.3.6媒体部施工管理员确认
确认画面已拆除，无残留。验收通过后，系统自动：标记工单及订单状态为“下刊完成”。若该资源有新的预订排队，则自动触发下一轮预订流程提醒。归档下刊记录，形成完整的资源使用生命周期档案。
3.4调度协同与动态保障管理
与营运公司广告专员对接的调度系统实时同步，强化线路、车辆动态变化的保障机制：
动态预警：若已预订/在刊资源对应的线路、车辆调整，系统自动触发预警，同步推送至广告公司媒体部与营运公司广告专员，明确影响范围与预计恢复时间；
应急处理：由营运公司广告专员联合广告公司媒体部评估影响（如更换同线路其他车辆、调整投放周期、替换线路车辆），并同步告知对应代理商/客户，确认后通过系统更新订单与工单信息，保障广告投放连续与运营顺畅；
日常协同：上刊/下刊工单发起时，自动校验调度计划，规避冲突；若需临时调整车辆使用，发起调度协调申请，经营运公司广告专员审批通过后执行。
3.5施工团队管理
建立施工人员档案，记录资质、工作经验、历史执行记录、进场登记记录等信息。支持工单分配、工作量统计，同时可追溯各工单的进场登记申请情况，提升施工团队管理效率与操作规范性。
4监测管理模块
实现广告投放过程中的实时监测与巡检，保障广告投放效果，及时发现并解决异常问题。
4.1刊间监测
系统按“每月一次”的标准自动生成全量广告（自营+代理商运营）的监测清单。由营运分公司的广告专员通过接收监测任务，形成监测记录，支持异常情况标注（如画面破损、遮挡）；巡检完成后自动生成月度监测报告，同步至广告公司媒体部与对应代理商。
4.2异常预警与破损报修管理
巡检发现异常后，系统自动触发预警，按运营模式区分责任主体推送通知；同时支持手动发起破损报修，具体流程如下：
报修发起：营运分公司广告专员、广告公司媒体部人员或代理商可通过系统发起破损报修，填写报修信息（破损广告点位、破损类型、破损程度、现场照片、报修人信息），系统自动关联对应订单与资源档案；
报修审核：广告公司媒体部对报修信息进行审核，核实破损真实性与影响范围，审核通过后生成维修工单或重做工单。
通知推送：审核完成后，系统自动将工单信息推送至对应责任主体（自营广告推送至媒体部施工团队，代理商运营广告推送至对应代理商）。
维修过程管控：针对无需重做的轻微破损，建立全流程维修跟踪机制：
工单分配：维修工单生成后，可手动或自动分配给指定维修人员，明确维修要求、完成时限；
进度跟踪：维修人员通过移动端接收工单，实时更新维修进度（待维修/维修中/已完成/无法维修），上传维修过程照片；
验收闭环：维修完成后，由营运分公司广告专员现场验收，上传验收照片，确认无误后完成维修闭环；验收不通过则要求重新维修，直至验收合格。
破损重做管理：针对严重破损无法维修的情况，支持原车重做与换车重做两种模式，流程如下：
	重做方案确认：广告公司媒体部审核后确定重做模式，若为原车重做，直接关联原车辆资源生成重做工单；若为换车重做，由营运分公司广告专员确认备选车辆调度可行性，确定替换车辆后生成重做工单，同步更新资源档案；
	重做执行：自营广告由媒体部施工团队执行重做，代理商运营广告由代理商自主执行重做，双方均需通过移动端上传重做过程照片（含材料准备、安装过程）；
	重做验收：重做完成后，经营运分公司广告专员现场验收（核查广告安装合规性、画面完整性），验收合格后完成重做闭环，系统更新广告状态为“在刊”；验收不合格则要求重新执行。
破损档案管理：建立破损档案库，自动归档所有破损报修记录、审核意见、维修/重做工单、过程照片、验收结果等信息，支持按广告点位、运营模式、破损类型等维度筛选查询，便于后续追溯与责任认定。支持生成月度综合监测报告，包含巡检详情、破损处理情况、维修/重做达标率等信息，供广告公司媒体部、代理商与客户查看。
5数据统计与分析模块
整合全业务流程数据，构建多维度数据分析模型，通过可视化仪表盘呈现，为经营决策提供数据支撑。
运营仪表盘：实时展示核心运营数据，如资源利用率、订单数量、上刊率、异常处理率、客户活跃度等，支持按时间（日/周/月/年）、区域、资源类型筛选查看。
多维度分析报表：支持生成销售分析报表（销售额、销售业绩、客户贡献度）、资源分析报表（资源利用率、热门点位排行）、执行分析报表（上刊效率、监测达标率）等。
数据导出与共享：支持报表在线查看、导出（Excel/PDF格式），支持数据权限管控，不同角色只能查看权限范围内的报表数据。支持数据对接企业BI系统，满足深度数据分析需求。
6媒体营销模块
整合资源销售展示、刊例价管理、销售方案输出核心能力，构建全链路营销支撑体系，通过可视化展示、灵活定价与智能方案生成提升销售转化效率，保障定价规范与方案专业。
6.1媒体资源展示
整合图片、3D模型等形式，全方位展示车身广告（不同车型广告位实拍图、安装效果模拟、车身3D套稿效果）、站点广告（广告灯箱实景图、周边环境介绍）。支持生成资源展示画册、电子沙盘，可一键分享给代理商或客户，直观呈现资源价值；车身3D套稿效果支持客户上传设计初稿后快速合成适配不同车型的预览效果，助力客户直观判断设计方案可行性。
6.2线路商业价值画像
针对车身广告线路，构建专属线路画像，包含线路属性（运营里程、途经站点、高峰时段客流）、人群画像（年龄分布、职业构成、消费习惯、出行目的）、覆盖场景（商圈、高校、医院、住宅区）等信息。支持按人群标签（如年轻消费群体、通勤白领、亲子家庭）筛选对应线路资源，精准匹配客户投放需求。
6.3刊例价全生命周期管理
建立刊例价档案库，按资源类型（车身/站点广告灯箱）、运营模式（自营/代理商运营）、规格、投放周期、季节等维度设定差异化刊例价。支持刊例价版本管理，记录价格调整历史（调整时间、调整原因、生效范围）；支持批量更新刊例价，新价格生效前自动提醒相关角色确认；支持针对不同代理商设置阶梯刊例价，关联代理等级与合作规模；同时支持按权限设定差异化折扣，不同角色（如销售、管理层）对应不同折扣权限，系统自动关联权限等级核算最终报价，兼顾定价灵活性与管控规范性。
6.4智能方案
方案模板库：内置标准化销售方案模板。模板包含固定模块（线路商业价值、线路走向，过经区域，地图，刊例价、历史广告展示等）与可编辑模块，适配不同行业客户需求。
智能方案生成：基于客户需求（投放区域、预算、人群、周期）与系统匹配的资源清单，AI自动填充方案核心内容，生成初步方案草稿。支持自动嵌入线路画像、人群分析、刊例价格、历史广告发布效果数据，减少人工编写工作量。
个性化定制：支持销售或代理商对方案草稿进行个性化。支持插入客户品牌元素、定制化数据图表，生成专属方案文档（Word/PDF格式），可直接导出分享。
方案审核与归档：建立按运营模式区分的方案审核流程：1. 自营广告方案：需经广告公司媒体部全流程审核（内容合规性、资源可行性、价格合理性、投放策略有效性），审核通过后推进执行；2. 代理商运营广告方案：仅需广告公司媒体部审核资源匹配度与合规性，审核通过后由代理商自主落地执行。支持方案版本管理与归档，记录方案修改轨迹、审核意见，便于后续追溯与优化。
7代理商费用结算管理模块
作为独立模块实现代理商费用结算的全流程管理，保障结算数据准确、流程规范，模块功能独立闭环，不与其他业务模块产生关联。
结算基础信息管理：建立代理商结算档案，记录代理商基本信息、结算账户、结算周期（月结/季结/年结）、结算方式（银行转账/电子承兑等）等基础信息，支持信息的新增、编辑、查询与归档。
结算数据录入：支持手动录入代理商结算相关数据，包括合作期间、涉及费用项目（代理费、服务费、返点等）、费用金额、计费依据等信息；支持批量导入结算数据（Excel格式），导入后系统自动校验数据完整性（如必填项是否缺失、金额格式是否正确）。
结算单生成与审核：基于录入的结算数据，自动生成标准化结算单，包含结算单号、代理商信息、费用明细、总金额、结算周期等内容。支持结算单的内部审核流程，可配置审核节点与审核角色，审核通过后标记为可结算状态。
结算状态跟踪：实时展示各结算单的状态（待录入、待审核、审核通过、已结算、已驳回），支持按代理商、结算周期、状态等维度筛选查询结算单，便于跟踪结算进度。
结算档案归档：所有结算单、结算审核记录、付款凭证等相关资料自动归档，形成代理商结算档案库，支持按条件检索与导出，便于后续对账与审计。
8审批与流程管理模块
构建灵活可配置的审批流程引擎，适配不同业务场景的审批需求，实现流程透明化、规范化，提升审批效率。
多流程配置：支持按运营模式（自营/代理商运营）自定义差异化审批流程，如自营广告的订单-合同-上刊全流程审批、代理商运营广告的订单-画面审查简化审批、费用审批等。可配置审批节点、审批角色、审批权限，适配不同规模广告公司的组织架构需求。
流程可视化追踪：审批流程发起后，相关角色可实时查看流程进度、当前审批节点、审批意见。支持流程催办、驳回重审、跳转审批等操作，保障流程顺畅流转。
跨角色协同联动：审批流程按运营模式清晰关联各角色：
	自营广告：订单审批、上刊审批均需广告公司媒体部全流程把控，上刊审批需同步营运分公司的广告专员确认调度可行性；
	代理商运营广告：订单审批、画面审查仅需广告公司媒体部合规性审核，审核通过后由代理商自主执行上下刊，上刊前需同步营运分公司的广告专员备案以协调调度资源。
实现跨部门协同闭环，确保流程顺畅与权责清晰。
9内部协同与任务管理模块
作为上海公交广告公司内部的标准化协同工作，专注于解决跨部门、跨角色的任务交办、协作与跟踪需求。模块独立于广告核心业务流程，旨在承接管理层指令下发、项目协同、临时事务等日常协作场景，实现任务从创建、执行到闭环的全流程数字化、透明化管理，切实提升组织内部执行力与协同效率。
任务线上化：将线下口头、群聊中的工作安排转化为结构化、可追踪的线上任务，杜绝遗漏。
权责清晰化：明确每项任务的发起人、负责人、参与人及时间要求，减少推诿与沟通成本。
进度透明化：为管理层提供实时全景视图，为执行者提供清晰待办指引，实现过程可视、风险可控。
执行高效化：通过自动化提醒、标准化流程与便捷的协作工具，加速任务流转与完成。
9.1任务创建与分发
多场景创建入口：协同中心主入口：提供标准任务创建表单。业务关联创建：在审批详情、项目看板等页面，支持一键创建关联任务（如“审批通过后需跟进合同盖章”）。快速模板创建：内置“会议决议落实”、“项目里程碑跟踪”、“客户拜访反馈”等常用模板。
结构化任务信息：基础要素：任务标题、详细描述（富文本）、优先级（高/中/低）、计划开始/截止时间、所属分类（如行政、项目、营销）。
执行设置:负责人：指定单人（必选）。参与人：设置需知悉或协作的多位同事。关注人：设置仅需同步进展的上级或相关方。
任务类型：选择“单线任务”（单人负责完成）或“流程任务”（多节点串行或并行处理）。
关联与附件：可关联至具体业务单据（如订单号、合同号），上传参考文件，并添加分项检查清单。

9.2任务处理与执行跟踪
个人工作台：为每个用户提供聚合视图，整合四大列表：我负责的：需由我主导完成的任务。我参与的：我作为协作人参与的任务。我发起的：由我创建并跟踪的任务。我关注的：我设置为关注者的任务。
任务处理动作：
接收与确认：负责人收到任务后，可点击“确认接收”或提出疑问。
进度更新：负责人可定期更新任务进度（百分比），并添加文字说明、上传中间成果。
子任务分解：复杂任务可分解为多个子任务，分别指派与跟踪，形成任务组。
协作互动区：每个任务均设有评论区，支持@同事、发表评论，沟通记录全程留存。
任务完成与交付：负责人认为任务完成后，可提交最终成果文件并点击“申请完成”，任务将流转至发起人处等待确认。
9.3任务确认、延期与闭环
发起人验收：发起人对完成结果进行审核，可“确认完成”或“驳回修改”。驳回时需注明原因，任务返回负责人重新处理。
延期管理：负责人若预判无法按期完成，可提前发起“延期申请”，说明原因与建议的新截止时间，由发起人审批。
任务归档：确认完成后，任务状态变为“已完成”，所有信息（描述、评论、文件、操作记录）锁定，便于后续查询与复盘。

9.4提醒、通知与透明度
提醒体系：
任务指派时：立即通知负责人与参与人。
进度更新时：通知发起人与关注人。
限期预警：截止时间前24小时、前2小时自动提醒负责人。
超期告警：任务超期未完成时，提醒负责人并抄送发起人。
多端消息触达：通过系统站内信、微信小程序服务通知进行实时推送。
管理全景看板：为管理层提供可视化看板，可按部门、人员、项目查看任务负荷、完成情况、超时统计等。
9.5统计与检索
多维统计报表：支持按部门、人员、时间周期统计任务数量、完成率、平均耗时、延期率等，为工作评估与效率优化提供数据支持。
全局搜索引擎：支持按关键词、参与人、时间范围、任务状态等条件，快速检索历史任务及相关讨论、文件，方便信息查找与回溯。
9.6权限与角色
全员:创建任务（可指派给同级或下级）、处理负责/参与的任务、评论、上传文件、检索已参与任务。
部门负责人:除全员权限外，可查看本部门所有成员的任务全景、进行部门内任务协调与再分配。
公司管理层:拥有跨部门任务全景查看权限、访问所有统计报表与管理看板。
系统管理员:维护任务分类模板、流程模板、通知规则等系统配置。
9.7差异化工作视图
员工视图：聚焦“个人工作台”，界面简洁，突出待办事项与近期任务。
团队负责人视图：在个人视图基础上，增加“团队任务看板”选项卡，可视化监控团队整体进度与负荷。
管理层视图：提供“公司协同全景”仪表盘，聚焦关键任务、跨部门协作瓶颈及组织效能指标。
10系统管理模块
保障系统安全、稳定运行，支持系统配置、权限管理、日志管理等功能。
角色与权限管理：基于RBAC模型，自定义角色，细化权限颗粒度（如资源查看权限、订单审批权限、数据查看权限），实现最小权限管控，保障数据安全。
系统配置：支持自定义系统参数（如审批流程配置、预警规则配置、报表模板配置），适配不同业务需求的个性化设置。
日志管理：记录系统操作日志、登录日志、异常日志等，支持日志查询、导出，便于系统运维与问题排查。
数据备份与恢复：支持自动定时备份系统数据，支持手动备份与恢复，保障数据安全性与完整性。
三.AI应用场景设计
1智能线路广告价值画像构建
基于公交运营大数据与外部环境数据，AI自动构建精准、动态的车身广告线路画像，为销售匹配与方案制定提供数据支撑。AI可整合线路的基础数据（途经站点）、周边场景数据（商圈等级、高校数量、医院规模、住宅区密度），通过算法挖掘数据关联关系，生成多维度线路标签（如“年轻消费主力线”“通勤商务线”“亲子家庭线”）。同时，AI支持线路画像的实时更新，当线路运营计划调整、车辆配置变化、周边场景变化时，自动同步更新画像数据；可对比不同线路的人群重合度与差异化特征，为组合线路投放提供数据依据，帮助销售快速匹配符合客户目标人群的线路资源。
2AI营销方案输出与车身广告效果生成
深度赋能销售方案全流程，实现方案智能生成与投放效果可视化预测。在方案生成阶段，AI基于客户需求（投放区域，广告类型）、匹配的资源清单及线路画像数据，自动填充方案框架，精准生成投放策略（如投放周期、线路组合）、预算明细（刊例价、优惠政策、总投入），并嵌入线路人群匹配度分析。针对车身广告，AI可生成可视化效果预览，：输入广告画面设计稿与目标车型，自动合成广告安装后的3D效果（含不同角度）；结合线路客流量、覆盖人群数据，预测投放后的曝光量、触达人数、目标人群触达率等核心效果指标，生成动态数据图表嵌入方案。此外，AI支持方案的快速迭代，当客户调整预算或投放需求时，自动重新计算资源组合与效果预测，大幅提升方案输出效率与专业性。
3AI智能广告审核
依托自然语言处理与计算机视觉融合技术，赋能广告画面与文案的全维度合规审核，提升审核效率与准确性。在广告画面审查模块的AI预审环节，AI可自动识别画面中的违规元素，包括虚假宣传表述（如“最”“第一”等绝对化用语）、不良导向图案、侵权商标/肖像、敏感人物/场景等；针对广告文案，AI可深度解析文本语义，检测是否违反《广告法》及行业规范，同时识别错别字、语法错误等基础问题。对于审核通过的内容，AI自动标记合规依据；对于疑似违规内容，精准定位问题位置并标注违规类型，推送人工复核并提供参考整改建议。此外，AI可学习历史审核案例，持续优化审核模型，适配不断更新的法律法规与审核标准，审核效率较纯人工提升5倍以上，违规漏审率降低至1%以下。
4AI数据洞察与决策支持（指令交互式输出）
构建指令交互式数据洞察体系，支持广告公司媒体部通过自然语言指令快速获取精准分析数据，辅助经营决策。用户可通过系统输入自然语言指令（如“分析2026年Q2快消行业自营车身广告销售数据”“统计本月代理商运营广告异常率”“预测下季度热门公交线路自营资源需求”“统计某代理商近半年回款率”），AI自动解析指令意图，调取对应业务数据，执行多维度分析（如趋势分析、对比分析、关联分析），并以可视化图表（折线图、柱状图、饼图）+ 文字解读的形式输出分析结果。支持分析结果的二次交互，用户可进一步追问（如“该数据与Q1相比增长原因”“热门线路的人群特征”“自营与代理商运营广告效果差异”），AI实时补充分析内容。同时，AI可自动识别数据异常（如某线路自营资源利用率骤降、某代理商回款延迟、月度巡检异常率超标），主动推送预警信息并附带原因分析建议，帮助管理人员快速响应问题，提升决策效率与精准度。

2总体技术架构
本系统采用分层式微服务架构设计，兼顾Web端与小程序双端交互体验，通过模块化拆分实现业务解耦与高效运维，核心架构分层如下：
前端层：Web端基于Vue3构建，承载系统管理、媒体库管理、广告预定、监测分析等全量后台操作；小程序聚焦现场作业、营销展示、统计分析等轻量化移动端场景，双端通过HTTPS/WebSocket与后端实时交互。
API网关层：作为前后端交互核心入口，提供请求路由、身份认证、负载均衡、限流熔断等能力，统一管控接口访问策略，保障系统稳定性与安全性。
业务服务层：拆解为系统管理、媒体资源、预定调度、AI监测等八大核心微服务，覆盖用户权限、线路/车辆/站台资源管理、广告上下刊调度、AI智能审核、费用结算、消息通知、数据报表等全业务流程，其中AI智能服务深度嵌入线路画像、内容审核、语义解析等场景，实现业务智能化提效。
数据服务层：采用PostgreSQL集群存储核心业务数据，Redis集群支撑缓存与会话管理，MinIO集群实现图片/视频/文档等附件存储，RabbitMQ负责消息队列与异步任务处理，多类存储组件协同保障数据高效存取。
外部集成层：对接营运系统获取线路/车辆/站点基础数据，集成高德地图服务实现资源可视化，调用AI模型服务（DeepSeek、内容审核、图像识别）赋能智能分析场景，完成跨系统数据互通与能力扩展。
3关键技术选型
3.1后端技术选型
核心开发框架：采用 Django 4.2 LTS 长期支持版本，基于 Django REST Framework3.14构建 RESTful API 接口，集成 djangorestframework-simplejwt 实现接口认证，通过 Celery + Redis 搭建异步任务队列，满足系统定时任务、批量处理等非实时性业务需求；对接久事公交集团高德地图 Geo 数据实现地理信息管理，基于 MinIO 分布式对象存储完成图片、视频、文档等文件的分片上传与存储。
数据库层：使用 PostgreSQL 作为核心业务数据库，依托 Django ORM 实现数据操作封装，集成 django-db-connection-pool 数据库连接池提升访问效率，通过 Django Migrations 完成数据库结构的版本化管理与迁移。
缓存与消息队列：采用 Redis 7.0 作为缓存中间件，通过 django-redis 适配 Django 生态，支撑缓存数据存储、用户会话管理、分布式锁等场景；基于 RabbitMQ 3.12 搭建消息队列，结合 Celery 实现任务异步调度，依托 EventBus 事件驱动架构完成跨服务消息通信。
3.2前端技术选型
Web 端：基于 Vue 3.3 核心框架构建，采用 Pinia 2.1 实现状态管理、Vue Router 4.2 完成路由控制，通过 Vite 4.4 提升工程构建效率；UI 层选用 Element Plus 2.3 组件库保障企业级交互体验，集成 ECharts 5.4 实现数据可视化、Three.js 完成 3D 效果渲染，对接高德地图 API 实现地理信息可视化展示；开发层面引入 TypeScript 保障类型安全，通过 ESLint + Prettier 统一代码规范，基于 Axios 封装 HTTP 请求、Day.js 处理日期格式。
小程序端：采用微信小程序原生开发框架，对 wx.request 进行封装优化，满足移动端轻量化网络请求需求。
3.3技术选型
核心基于 DeepSeek 大模型构建智能能力底座，推理层面适配 vLLM / 千问系列模型提升响应效率；集成 PaddleOCR / 千问系列模型实现 OCR 文字识别，依托千问系列模型完成图像识别、内容审核等智能分析场景，赋能线路画像、广告合规审查、破损识别等核心业务
3.4系统集成设计
支持与外部系统对接，实现数据互通与业务协同：
营运公司调度系统：深度对接营运公司调度系统，实时同步线路调整、车辆运营状态、站点维护计划等数据，为资源状态管控、订单审批、上下刊确认提供动态数据支撑，保障广告执行与运营协同。
微信提醒：对接协同办公平台，实现审批提醒、消息推送、人员同步等功能，提升协同效率。
